Cần **macOS 11 (Big Sur)** trở lên.

> **Bản này chưa được ký số (unsigned).** Lần đầu mở: chuột phải vào Nixi → **Open**. Nếu macOS báo *"Nixi is damaged and can't be opened"*, chạy lệnh dưới rồi mở lại:

> ```bash

> ```

## Sửa lỗi
- **SSH tới server cũ** (CentOS/RHEL 5–6, OpenSSH 5.x, Cisco, Juniper, HP đời cũ): trước đây báo `Handshake failed: no matching…` hoặc `Timed out while waiting for handshake` trong khi MobaXterm/Termius vào được.
  - Hỗ trợ thêm các thuật toán cũ giống MobaXterm/Termius: key exchange SHA-1 (`group1`, `group14`, `group-exchange`), mã hoá CBC / 3DES / arcfour, MAC MD5 / SHA1-96. Các thuật toán này đứng sau thuật toán hiện đại, nên server mới vẫn kết nối như trước.
  - Group exchange với số nguyên tố lớn (OpenSSH cũ hay gửi 8192 bit) không còn treo ~30 giây.
  - Server đăng nhập chậm (thường do `UseDNS` / `GSSAPIAuthentication` khi server không tra được DNS của máy mình) giờ được chờ tới 90 giây. Host không trả lời vẫn báo lỗi sau 20 giây.
  - Khi hết giờ, thông báo nói rõ kẹt ở bước nào: không kết nối được, đang trao đổi khoá, hay đã mã hoá nhưng đăng nhập chậm.
- Host key DSA (`ssh-dss`) vẫn chưa hỗ trợ; server chỉ có loại key này sẽ có thông báo nói rõ.
