# Nixi 0.7.1 — sắp xếp credential

## Tải về

| File | Dành cho |
|---|---|
| `Nixi-0.7.1-arm64.dmg` | Mac chip Apple (M1, M2, M3, M4…) |
| `Nixi-0.7.1-x64.dmg` | Mac chip Intel |

Cần **macOS 11 (Big Sur)** trở lên.

> **Bản này chưa được ký số (unsigned).** Lần đầu mở: chuột phải vào Nixi → **Open**. Nếu macOS báo *"Nixi is damaged and can't be opened"*, chạy lệnh dưới rồi mở lại:
>
> ```bash
> xattr -cr /Applications/Nixi.app
> ```

## Thay đổi
- **Sắp xếp credential:** trong hộp Credentials, kéo-thả dòng hoặc dùng nút ↑↓ trên dòng đang chọn, giống như macro. Thứ tự được lưu và dùng ở hộp đăng nhập, hộp sửa session và danh sách mật khẩu đã lưu khi shell hỏi mật khẩu (⌘J).
