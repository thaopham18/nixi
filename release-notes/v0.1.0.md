# Nixi 0.1.0 — bản phát hành đầu tiên

Nixi là ứng dụng remote all-in-one kiểu MobaXterm, làm cho **macOS**. Một cửa sổ có đủ SSH, SFTP, RDP, Telnet, terminal local, tunnel và macro. Toàn bộ session, mật khẩu và cài đặt nằm trong **một file database mã hoá**.

## Tải về

| File | Dành cho |
|---|---|
| `Nixi-0.1.0-arm64.dmg` | Mac chip Apple (M1, M2, M3, M4…) |
| `Nixi-0.1.0-x64.dmg` | Mac chip Intel |

Cần **macOS 11 (Big Sur)** trở lên.

> **Bản này chưa được ký số (unsigned).** Lần đầu mở: chuột phải vào Nixi → **Open**. Nếu macOS báo *"Nixi is damaged and can't be opened"*, chạy lệnh dưới rồi mở lại:
>
> ```bash
> xattr -cr /Applications/Nixi.app
> ```

## Có gì trong bản này

### Kết nối
- **SSH**:
  - Đăng nhập bằng password, private key (có passphrase), ssh-agent hoặc keyboard-interactive.
  - Đi qua jump host (ProxyJump), có keepalive và lệnh tự chạy sau khi vào.
  - Kiểm tra host key kiểu TOFU và cảnh báo khi key đổi.
  - Mật khẩu sai thì hỏi lại ngay.
- **RDP chạy ngay trong tab**, không cần cài thêm app:
  - Hỗ trợ NLA/CredSSP, clipboard text, Ctrl+Alt+Del.
  - Mỗi session chọn được mở bằng Windows App / mstsc nếu cần hình mượt hơn.
- **Telnet** cho switch/router: tự đăng nhập, tự báo kích thước cửa sổ, chọn được bảng mã UTF-8 hoặc Latin-1.
- **Terminal local** (zsh/bash/PowerShell).

### Làm việc với nhiều máy
- **Tab**:
  - Tab đang mở nối liền với terminal bên dưới nên nhìn là biết đang ở đâu.
  - Màu riêng cho từng session, ghim (pin) tab.
  - Đóng các tab bên trái, bên phải hoặc tất cả. Có nút ‹ › để cuộn khi mở nhiều tab.
  - Tab đang ẩn mà có output mới thì tên tab sáng lên chậm như nhịp thở.
- **Split view**:
  - Kéo tab hoặc session vào trái/phải/trên/dưới/lưới để xem nhiều máy cùng lúc. Kéo thanh chia để đổi kích thước.
  - Di chuyển pane không làm rớt kết nối.
- **Multi-exec**: gõ một lần, gửi tới mọi terminal. Bỏ chọn được từng pane.
- **Thanh thông tin server** dưới terminal SSH: CPU, RAM, mạng, load, uptime. Các ổ đĩa người dùng tạo đều hiện kèm % đã dùng, ổ hệ thống nằm trong popup.

### SFTP
- Duyệt file ngay ở sidebar, mở tự động khi SSH kết nối. Có tạo folder, đổi tên, chmod, xoá.
- **Kéo thả hai chiều**:
  - Thả file từ Finder vào để upload, thả lên một folder để upload vào folder đó.
  - Kéo file hoặc folder ra Finder/Desktop thì tải về **đúng chỗ thả**.
- Mỗi lần upload/download nhiều file chỉ hiện **một dòng tiến trình**.
- **Trùng tên ở đích** thì hỏi: ghi đè, giữ cả hai (thêm hậu tố 5 số) hoặc huỷ.
- Download bằng chuột phải thì được chọn thư mục lưu.
- Double-click để sửa file bằng editor ngoài, lưu xong tự upload lại.

### Tunnel
- Local (-L), Remote (-R) và Dynamic SOCKS5 (-D), vẽ thành sơ đồ máy mình → SSH server → máy đích.
- Có preset cho Web, MySQL, PostgreSQL…
- Tự chạy khi mở app và tự kết nối lại khi rớt.

### Macro
- Ghi macro từ bàn phím, hoặc soạn bằng text: gửi lệnh, chờ, chờ đến khi có chữ mong muốn.
- Gán phím tắt cho từng macro.
- **⌘J mở danh sách macro ngay tại con trỏ**:
  - Chạy được trong terminal và **trong mọi ô nhập**, kể cả ô mật khẩu.
  - Đổi được phím ⌘J, chọn tổ hợp nào cũng được.

### Dữ liệu và bảo mật
- **Một file `nixi.nxdb`** (kiểu KeePass), mã hoá AES-256-GCM bằng master password (scrypt). Copy file này hoặc để trong iCloud/Dropbox là dùng được trên máy khác.
- Tuỳ chọn mở khoá tự động trên máy này (khoá lưu trong Keychain). Có Lock và đổi master password (nhập sai báo ngay).
- Import `~/.ssh/config`. Import/export **MobaXterm** (`MobaXterm.ini`, `.mxtsessions`), giữ nguyên cấu trúc folder. Mật khẩu không bao giờ bị export.
- Giao diện chạy trong sandbox, mọi kết nối mạng đi qua process chính.

### Giao diện
- 3 theme: Dark, Light, Solarized. Bo góc đồng bộ, scrollbar mảnh.
- **Tự chọn màu chữ, màu nền và màu con trỏ của terminal**, có xem trước và cảnh báo khi chữ khó đọc.
- Toolbar và thanh thông tin tự thu gọn khi cửa sổ hẹp. Hỗ trợ full screen.

## Hạn chế đã biết
- Bản chưa ký số và chưa notarize (xem hướng dẫn mở ở trên).
- RDP nhúng giải mã bằng CPU nên không mượt bằng client chính chủ. Cần mượt thì chọn mở bằng Windows App.
- RDP chưa có chuyển file qua clipboard, âm thanh và nhiều màn hình.
- Cùng một file database bị sửa trên hai máy thì bản lưu sau đè bản trước, chưa gộp thay đổi.
- Giải mã macro MobaXterm bằng master password đang ở mức thử nghiệm.

## Tự build từ mã nguồn

Cần Node.js ≥ 20. Trên macOS nên có Xcode Command Line Tools (`xcode-select --install`).

```bash
npm ci
npm run dev            # chạy thử
npm run dist:mac       # tạo .dmg cho máy đang dùng
```
