# Nixi 0.2.0 — thêm VNC

Bản này thêm **VNC chạy ngay trong tab**, nối được máy Mac, Windows và Linux mà không cần cài thêm app.

## Tải về

| File | Dành cho |
|---|---|
| `Nixi-0.2.0-arm64.dmg` | Mac chip Apple (M1, M2, M3, M4…) |
| `Nixi-0.2.0-x64.dmg` | Mac chip Intel |

Cần **macOS 11 (Big Sur)** trở lên.

> **Bản này chưa được ký số (unsigned).** Lần đầu mở: chuột phải vào Nixi → **Open**. Nếu macOS báo *"Nixi is damaged and can't be opened"*, chạy lệnh dưới rồi mở lại:
>
> ```bash
> xattr -cr /Applications/Nixi.app
> ```

## Có gì mới

### VNC
- **Hỗ trợ nhiều loại server:**
  - macOS Screen Sharing, đăng nhập bằng tài khoản Mac.
  - TightVNC và UltraVNC (MS-Logon II) trên Windows.
  - TigerVNC, x11vnc, wayvnc và QEMU/KVM trên Linux.
  - VeNCrypt + TLS X509, kiểm tra chứng chỉ khi gặp lần đầu giống SSH.
- **Đi qua SSH:** chọn một session SSH đã lưu, hợp với server chỉ nghe localhost.
- **Hiển thị:** vừa tab, đúng kích thước (có thanh cuộn), hoặc đổi độ phân giải máy xa.
- **Chất lượng hình:** Smooth, Balanced hoặc Sharp, có tác dụng với server nén JPEG như TigerVNC và TightVNC.
- **Clipboard text 2 chiều:** mỗi session tắt được việc tự gửi clipboard sang máy xa, khi đó dùng nút **Send clipboard**.
- **Điều khiển:** View only, Ctrl+Alt+Del, Reconnect, mở bằng app VNC của hệ thống.
- **Đỡ giật trên mạng có độ trễ:** Nixi xin trước vài khung hình thay vì chờ từng khung một.
- **Stats:** xem trực tiếp số khung hình, tốc độ dữ liệu, thời gian giải mã và kiểu nén đang dùng.
- **Mật khẩu:** nhập sai thì hỏi lại ngay, có thể lưu vào database mã hoá.
- **Làm việc chung với phần còn lại:** dùng được trong split view, di chuyển pane không rớt kết nối, import session VNC từ MobaXterm.

### Cải thiện khác
- Toolbar của RDP và VNC tự bớt nút khi pane hẹp.

## Hạn chế đã biết
- **VNC chưa được kiểm tra đủ với máy thật:** phần lớn loại server mới test với server giả; riêng macOS Screen Sharing đã dùng thử với một máy thật.
- **macOS Screen Sharing:** gõ lệnh ổn, nhưng hiệu ứng của Mac (như phóng to Dock) bị giật, nhất là ở độ phân giải Retina. Hạ độ phân giải máy Mac, dùng hình nền một màu và bật Reduce motion sẽ đỡ hơn. Cần mượt thì mở bằng app Screen Sharing.
- **Chưa kết nối được:** RealVNC khi server chỉ cho mã hoá RA2, và VeNCrypt anonymous TLS. Nixi báo rõ lý do trong tab.
- **Export sang MobaXterm:** bỏ qua session VNC.
- Bản chưa ký số và chưa notarize. RDP nhúng và database vẫn có các hạn chế như [bản 0.1.0](https://github.com/thaophamwithai/nixi/releases/tag/v0.1.0).

## Tự build từ mã nguồn

Cần Node.js ≥ 20. Trên macOS nên có Xcode Command Line Tools (`xcode-select --install`).

```bash
npm ci
npm run dev            # chạy thử
npm run dist:mac       # tạo .dmg cho máy đang dùng
```
