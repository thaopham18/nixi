# Nixi 0.5.0 — trợ lý AI, gõ tiếng Anh trong terminal, tunnel làm lại

## Tải về

| File | Dành cho |
|---|---|
| `Nixi-0.5.0-arm64.dmg` | Mac chip Apple (M1, M2, M3, M4…) |
| `Nixi-0.5.0-x64.dmg` | Mac chip Intel |

Cần **macOS 11 (Big Sur)** trở lên.

> **Bản này chưa được ký số (unsigned).** Lần đầu mở: chuột phải vào Nixi → **Open**. Nếu macOS báo *"Nixi is damaged and can't be opened"*, chạy lệnh dưới rồi mở lại:
>
> ```bash
> xattr -cr /Applications/Nixi.app
> ```

## Có gì mới

### Trợ lý AI
Tab AI ở sidebar: hỏi AI về chuyện đang xảy ra trong terminal, bằng API key của bạn.

- **Chọn hãng:** Anthropic, Gemini, hoặc Custom cho mọi server có API kiểu OpenAI (OpenAI, OpenRouter, Ollama, LM Studio…). Mỗi lúc chat dùng một hãng, đổi ở Settings → AI Assistant.
- **Model:** danh sách lấy từ API của hãng, gõ tay được, nên model mới dùng được ngay mà không cần ra bản app.
- **Chạy lệnh:** Ask me thì AI chỉ đề xuất, bạn bấm Run. Auto thì AI tự chạy lệnh chỉ đọc (xem, select, thu thập thông tin); lệnh thêm, sửa, xoá, lệnh nguy hiểm và lệnh không nhận ra vẫn hỏi.
- **Dữ liệu:** chỉ gửi khi bạn gửi tin. Xem trước được phần gửi kèm, bí mật phổ biến và mật khẩu đã lưu được che. Key nằm trong database mã hoá, không có trong file export.

### Chỉ tiếng Anh ở SSH và Telnet
Bộ gõ tiếng Việt và bảng chữ khác không làm sai lệnh hay mật khẩu nữa. Paste vẫn giữ tiếng Việt, Local không bị ảnh hưởng. Bật sẵn, tắt ở Settings → Keyboard & Paste.

Trên macOS, khi đang gõ trong terminal SSH hoặc Telnet, Nixi bật Secure Keyboard Entry để chặn EVKey, OpenKey, GoTiengViet. Trong lúc đó app khác theo dõi bàn phím cũng tạm dừng; chuyển cửa sổ là tắt.

### Tunnel
- **Sửa lỗi Stop:** tunnel đã tắt mà vẫn hiện nút Stop và màu xanh. Bấm Stop lúc đang kết nối giờ cũng tắt hẳn, trước đây tunnel vẫn chạy.
- **Tự kết nối lại:** thử mỗi 3 giây, tối đa 200 lần, trước đây chỉ thử 1 lần. Có nút Stop trong lúc chờ, server từ chối mật khẩu thì dừng, và theo setting tự kết nối lại chung.
- **SSH server:** chọn từ session đã lưu hoặc tự gõ `user@host:port`, kèm mật khẩu hoặc dùng SSH key.
- **Giao diện mới:** mỗi tunnel một dòng đường đi, form nhập đi theo đúng chiều dữ liệu.
- **Sửa tunnel đang chạy:** nút thành Save and restart và chạy lại với cấu hình mới.

### SFTP Follow terminal
Chạy được với bash trên Ubuntu và đa số server, vì giờ đọc thư mục từ prompt. Không nhảy khi đang gõ hay khi đang ở less, vim. Thư mục SFTP không vào được thì báo rõ và giữ danh sách cũ.

### Settings
Sắp xếp thành các tab bên trái như System Settings của macOS. Nút nào đưa bạn tới Settings (ví dụ Add API key) thì mở đúng trang và đúng ô.

### Khác
Mở database chỉ mở thư mục đầu tiên trong cây session.

## Hạn chế đã biết
- Chưa có bản dựng và kiểm thử trên Windows, Ubuntu.
- **Trợ lý AI mới kiểm thử bằng API giả lập**, chưa gọi API thật của hãng nào. Có thể gặp lỗi tham số khi dùng key thật.
- Output từ server vẫn có thể lừa AI đọc thêm dữ liệu rồi gửi lên hãng khi bật Auto. Phân loại lệnh chỉ đọc chỉ nhìn chữ của lệnh, không phải ranh giới bảo mật.
- Mật khẩu chỉ gõ tay, không lưu thì không che được theo giá trị.
- Chặn bộ gõ trên macOS chưa thử với EVKey thật. Trên Windows chưa chặn được Unikey, EVKey; hãy thêm Nixi vào danh sách loại trừ của bộ gõ.
- Tunnel tới server tự gõ chưa đi qua jump host được. Tunnel mới kiểm thử với SSH server giả lập.
